Envia.com for Odoo

Connect with Envia.com and quote live carrier rates on sales orders

Key Features

  • OAuth connection between Odoo and Envia.com (external plugin flow).
  • Live shipping rates from Envia.com inside Add shipping on sale orders.
  • Compare carrier services (DHL, FedEx, Estafeta, Paquetexpress, and more).
  • Home delivery and branch pickup/drop-off routes (configurable).
  • Default origin address and preferred carriers in Settings.
  • Package weight taken from product master data for accurate quotes.
  • Shipping API token stored automatically through the Envia.com integration callback.

Installation

Install only Envia.com (envia) from Apps. Odoo installs every module dependency automatically (Sales, Inventory, Delivery, and related apps).

Odoo.sh / Apps Store

  1. Use Deploy on Odoo.sh (or put this package on the addons path).
  2. Update Apps List and install Envia.com (envia).

On-premise

  1. Put the envia folder on the Odoo addons path.
  2. Install Envia.com (envia) from Apps.

Connect Odoo with Envia.com

The welcome wizard guides administrators through OAuth authorization. Envia.com validates your public store URL and completes the integration on their portal.

Settings

Open Envia.com → Settings, generate the Odoo API key, complete the connection, and set your default ship-from address and carriers.

Prepare your products

Before quoting, set weight on each product (Inventory tab — built into Envia.com). Envia.com uses it to calculate rates; missing values fall back to 1 kg.

Quote shipping on sale orders

Open any quotation or sale order in the Sales app and use the native Add shipping button. Envia.com rates appear without leaving Odoo.

  1. In Sales, open a quotation or sale order and click Add shipping.
  2. Choose Envia.com as the shipping method.
  3. Review origin and destination, then click Get rate.
  4. Select a carrier service and click Add.
  5. The shipping line and selected Envia rate appear on the order.

Configuration Overview

Connection Link your Odoo store with Envia.com. Module and plugin versions are shown after a successful connection.
Odoo API key Generated in Settings. Envia.com sends it when calling back into Odoo.
Envia shipping token Saved by Envia.com during integration. Used for quoting and labels on api.envia.com.
Shipping defaults Default origin partner, carriers, optional Envia pre-selection, and branch routes.

External Service Notice

This module connects to Envia.com APIs to register your store and request shipping quotes. When you quote, Odoo sends address, contact, package, and order data to Envia.com. Label creation and tracking are not included in this version. You need an active Envia.com account and must accept Envia.com terms of service. The integration callback requires a publicly reachable Odoo URL (typical for Odoo.sh and on-premise deployments).
